Capability statement

WebMCP · claim-capped

Review the change. Bound the action.

Ceiling is a WebMCP release-policy review console. An agent can inspect a synthetic policy, propose one typed change, and explain why. Policy blocks forbidden values; a person retains exact one-use authority over every admitted effect.

Ceiling This demonstration changes only in-memory synthetic release policy. It has no deployment, operating-system, filesystem, credential, payment, messaging, or cross-origin authority. Browser activation is not identity attestation. Receipts are verified session-local evidence, not signed or persistent audit records.
